### 问题处理

1. 访问 `pypi.ngc.nvidia.com` 出现 TLS EOF；同一网络下 PyPI 和 `pypi.nvidia.com` 可访问。通过本次命令忽略旧 pip 配置、显式使用可访问的官方源完成安装；未关闭 TLS 验证，未确定失败源的最终注入来源。
2. `flatdict==4.0.1` 需要 `pkg_resources`，固定 `setuptools==80.9.0` 后以 `--no-build-isolation` 单独安装。
3. 官方安装脚本引入较新依赖，随后固定 tensordict、IPython、psutil、Hugging Face 相关包等，并补装匹配的 torchaudio。
4. 最后一次 `python -m pip check` 显示 `No broken requirements found.`。
5. 初次 GUI 出现无响应；之后自定义静态脚本最终正常显示 G1。未证明所有 GUI 场景的卡顿原因已排除，加载时曾出现约一分钟的等待。

## 已阅读的训练配置

环境：`unitree_rl_lab/source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/robots/g1/29dof/velocity_env_cfg.py`

PPO：`unitree_rl_lab/source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/agents/rsl_rl_ppo_cfg.py`

| 项目 | 当前配置 |
| --- | --- |
| 地形 | 当前子地形仅平地，不能根据变量名认为是石子路 |
| 仿真与控制 | dt=0.005 秒，decimation=4，即 200Hz 物理 / 50Hz 动作 |
| 初始目标 | x/y 速度 ±0.1m/s，转向速度 ±0.1rad/s |
| 课程范围上限 | x=-0.5～1.0m/s，y=±0.3m/s，yaw=±0.2rad/s；扩展条件尚未逐行分析 |
| 动作 | 29 关节位置目标，默认角度 + 0.25×动作值；0.25 不是硬角度范围 |
| 观测 | 角速度、重力方向、速度指令、关节位置/速度、上次动作，历史长度 5 |
| 奖励 | 速度跟踪、存活、直立、根部高度、交替迈步、抬脚；惩罚打滑、动作突变、过大关节运动等 |
| 随机化 | 摩擦、躯干质量、初始状态；每 5 秒水平速度扰动 |
| 回合 | 最长 20 秒；根部低于 0.2m 或倾角超过 0.8rad 提前终止 |
| 网络 | Actor/Critic 隐藏层均为 [512, 256, 128]，ELU |
| PPO | 每环境采样 24 步，5 个 epoch，4 个 mini-batch |
| 学习率 | 初始 0.001，adaptive，desired_kl=0.01 |
| 其他 | gamma=0.99，lambda=0.95，clip=0.2，entropy_coef=0.01 |
| 保存 | save_interval=100，默认 max_iterations=50000 |
